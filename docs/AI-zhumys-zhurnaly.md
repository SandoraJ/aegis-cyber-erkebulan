# AEGIS CYBER жобасының ЖИ-мен жұмыс журналы

Бұл журналда ChatGPT қолданылған қадамдар мен тексеру нәтижелері жинақталған. Сұраныстардың мазмұны қысқартылып берілді. Нақты сынақтар жобаға қосылған.

## 1. Техникалық тапсырманы құрастыру

**Сұраныс.** «Создай полноценный адаптивный сайт AEGIS CYBER…» Брифте орысша интерфейс, төрт қызмет, үш мысал, FAQ және консультация формасы берілді. Қосымша файл жеке кабинет, CRUD, байланысқан кестелер, Git және сынақтарды талап етті.

**ЖИ ұсынған шешім.** Басты бетке қызметтер мен консультация формасын, жеке кабинетке тіркелуді және басқару әрекеттерін орналастыру. Аккаунтсыз өтінім жіберуге мүмкіндік беру. Кабинетте аккаунтқа байланысты жазбаларды көрсету.

**Тексеру.** Беттер, API маршруттары мен ER байланыстары есепке енгізілді. Үлгі кейстер «Пример проекта» деп белгіленді. Ойдан шығарылған клиент көрсеткіштері қолданылған жоқ.

## 2. Басты бет пен бейімделу

**Тапсырма.** Графит фон, көгілдір акцент, екі әрекет батырмасы және шыны ядросы бар қорғалған желі иллюстрациясын жасау. Мәзір, қызметтер және FAQ пернетақтамен басқарылуы керек.

**ЖИ ұсынған шешім.** CSS торы, жабысқақ шапка, `details` пен `summary`, қозғалысты азайту параметрі және суреттің сығылған JPEG нұсқасы.

**Қате және түзету.** Алғашқы нұсқада ұзын тақырып мәтіні тар экранда өз аймағынан асып кетті. Chromium-да тақырыптың `scrollWidth` және `clientWidth` мәндері салыстырылды. Мобильді өлшем кішірейтілді, планшетте сурет оң жаққа ығысты. 360, 768 және 1440 px өлшемдері қайта тексерілді.

## 3. Сервер және деректер қоры

**Тапсырма.** Өтінім деректерін тексеру, тұрақты SQLite қоймасына сақтау және сақталғаннан кейін ғана растау. Тіркелу, кіру және жеке өтінімге CRUD қосу.

**ЖИ ұсынған шешім.** `users`, `services`, `applications`, `sessions` және `rate_limits` кестелері. Бір ортақ сервер өңдегіші, локалды SQLite бейімдегіші және жариялауға арналған Worker. Бір сұрауды қайта жіберуді анықтайтын кілт.

**Тексеру.** Қате өрістер SQLite-қа жазылмады. Қатар келген бірдей кілтті сұраулар бір идентификатор алды. SQLite файлы қайта ашылып, сақталған жазба оқылды. Басқа аккаунт бөтен жазбаны көре, өзгерте немесе жоя алмады.

## 4. Қауіпсіздік және қателерді өңдеу

**Тапсырма.** SQL сұраулары, браузерде мәтін көрсету, құпия сөз сақтау және қайталанатын жіберулерді тексеру.

**ЖИ ұсынған шешім.** Параметрленген SQL, `textContent`, тұздалған PBKDF2 хэші, сессия токенінің хэші, қауіпсіз cookie, `Origin` және жіберу жиілігін тексеру.

**Қате және түзету.** Кабинетте өңдеу аяқталғанда батырманың алдыңғы мәтінін қалпына келтіру жаңа күйді басып жазуы мүмкін болды. Мәтін батырма әлі жіберу режимінде тұрса ғана қалпына келтірілетіндей өзгертілді. Браузерлік сынақ өтінімді өңдегеннен кейін батырманың дұрыс аталуын тексерді.

## 5. Сынақ және жариялау

**Тапсырма.** Кемінде бес сынақ жазып, форма мен кабинет сценарийін орындау. Git тарихын және жариялау нұсқаулығын дайындау.

**ЖИ ұсынған шешім.** Node сынақтарына сегіз сценарий, интерфейске Chromium тексерісі және Git bundle әзірленді.

**Тексеру кезінде анықталған шектеу.** Алғашқы API сынақтары loopback желісіне қосыла алмады. Олар тікелей жиналған Worker-ді шақыратындай өзгертілді. Chromium сұраулары осы Worker-ге бағытталып, нақты SQLite деректер қорымен тексерілді. Хостингтің Git сервері мен GitHub атаулары қолжетімді ортада DNS арқылы шешілмеді. Жарияланған сайтқа және GitHub репозиторийіне сілтеме осы себеппен жоқ.

## Қорғауда көрсету

1. Қызмет карточкасынан форманы ашып, автоматты таңдалған қызметті көрсету.
2. Бос немесе қате email енгізіп, клиенттік валидацияны түсіндіру.
3. Өтінімді жіберіп, сервердің растауын және SQLite жазбасын көрсету.
4. Жеке кабинеттен өтінім құру, өңдеу және жою.
5. Екі байланысты кестені және өтінім иесінің рұқсаты қай жерде тексерілетінін түсіндіру.
